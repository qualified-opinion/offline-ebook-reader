# Offline Ebook Reader

A simple, offline-capable ebook reader that runs in your browser.

## Features
- Load local EPUB, PDF, or TXT files
- No internet required after initial load
- Clean reading interface
- Progress tracking (basic)

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
3. Select a local ebook file

## Tech
- Pure HTML/CSS/JS
- Uses File API for local file access
- Compatible with epub.js for EPUB support (can be extended)
